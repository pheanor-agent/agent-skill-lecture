사례와 시연

이 강의 제작 세션에서 교육용 합성 자료와 명시된 Skill 파일을 실제로 읽고 분류·보고서 초안을 작성한 기록입니다.

같은 세션에서 자료를 이미 본 뒤 명시적 사용 순서를 다시 확인했습니다. 새 세션의 자동 발견·자동 선택, 블라인드 평가, 정확도 향상 실험 또는 화면 녹화가 아닙니다.

예외 문제는 기대 동작의 설명이며 실행 결과가 아닙니다. 60분은 발표 계획 예산입니다.

글꼴과 라이선스

본문과 코드 내 한글은 동일한 Noto Sans CJK KR을 사용합니다. 배포 글꼴은 전체 한국어 글리프를 포함하는 WOFF2입니다. 코드는 시스템 고정폭 라틴 글꼴과 명시적 Noto 한글 fallback을 사용합니다.
