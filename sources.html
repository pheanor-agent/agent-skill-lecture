실제 시연 기록과 원본

실제 기록은 준비된 Codex 제작 세션에서 명시한 Skill·원자료·서식 파일을 읽고 분류·초안을 작성한 기록이다. 원시 도구 호출 페이로드나 녹화는 아니며 동작 설명도와 구별한다. 자료를 이미 본 뒤 사용 순서를 확인했으므로 자동 선택이나 성능 비교의 근거가 아니다.

형식과 앱별 사용

공통 Skill 형식과 앱의 배치·호출·공통 지침·도구 지원은 구분한다. 본편 Codex 예는 .agents/skills/weekly-brief/SKILL.md 및 $weekly-brief이다. Claude 등 다른 앱의 경로와 호출은 해당 공식 문서에서 확인한다.

  • https://agentskills.io/specification
  • https://learn.chatgpt.com/docs/build-skills
  • https://learn.chatgpt.com/docs/agent-configuration/agents-md
  • https://modelcontextprotocol.io/docs/learn/architecture
