출처와 확인 범위

공식 원문 확인일: 2026-11-04. 아래 요약은 해당 원문이 뒷받침하는 범위로 한정했습니다. 제품별 동작은 바뀔 수 있으므로 실제 사용 전 현행 문서를 확인하세요.

개념 주장과 원문

  1. Tool call은 호출 의도와 실제 실행/결과가 구분됩니다.
    OpenAI API — Function calling — 모델이 호출을 제안하고 앱이 도구를 실행한 뒤 결과를 돌려주는 흐름.
  2. MCP는 앱과 서버의 연결 구조이며 tools·resources·prompts를 다룰 수 있습니다.
    Model Context Protocol — Server concepts; Architecture.
  3. AGENTS.md는 프로젝트 문맥·지침을 전달하는 파일 관례입니다. 자동 발견·적용은 호스트별입니다.
    AGENTS.md; Codex documentation — AGENTS.md.
  4. Agent Skill은 SKILL.md와 선택적인 지원 파일을 묶는 형식이며 권한/재학습을 뜻하지 않습니다.
    Agent Skills specification; What are Skills?.
  5. 점진적 로딩은 설명→본문→필요한 지원자료 순으로 접근하는 설계입니다.
    Agent Skills specification — progressive disclosure. 이 강의는 개념도를 설명하며 특정 호스트의 정확한 런타임 추적을 주장하지 않습니다.
  6. Anthropic의 공개와 표준화는 서로 다른 두 이정표입니다.
    Anthropic — Equipping agents for the real world with Agent Skills — 2025-10-16 공개, 2025-12-18 원문 갱신에서 open standard 공표.
  7. MCP는 별도의 연결 표준이며 Agent Skills의 이전 세대가 아닙니다.
    Anthropic — Introducing the Model Context Protocol — 2024-11-25 공개.
  8. Codex의 Skill 경로와 명시 호출은 Claude Code와 다릅니다.
    Codex — Skills: 저장소 `.agents/skills//SKILL.md`, 사용자 `~/.agents/skills//SKILL.md`, `$skill-name` 호출 안내.
  9. Claude Code는 `.claude/skills` 경로와 `/skill-name` 호출을 문서화합니다.
    Claude Code — Skills: 저장소·사용자 범위의 경로 및 자동/명시 사용.
