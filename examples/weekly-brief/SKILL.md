# 주간업무 보고서 초안

이 예제는 합성 자료를 이용한 교육용 스킬입니다. 보고서 초안만 작성하며 외부 시스템으로 전송하거나 원자료를 수정하지 않습니다.

## 입력과 결과
- 기간 예시: 2026-10-26~2026-10-30 (KST)
- 데이터: `assets/input-example.json`
- 서식: `assets/report-template.md`
- 네 가지 테스트: `assets/test-cases.json`
- 결과에는 완료·진행·막힘의 세 구역과 근거 식별자를 포함합니다.

## 절차
1. 요청에서 보고 기간과 대상 팀을 확인합니다. 기간이 모호하면 질문합니다.
2. 제공된 자료나 현재 호스트에서 실제 사용할 수 있는 조회 도구로 과제·이슈·회의 메모를 확인합니다. 이 예제의 ID 경로는 교육용 식별자이며 실제 도구나 URL이 아닙니다.
3. 과제·이슈의 원래 상태를 확인하고 완료·진행·막힘으로 분류합니다. 확인 자료를 가져오지 못했으면 추측하지 말고 미확인으로 표시합니다.
4. 각 항목 옆에 근거 식별자를 남깁니다. 이 사례에서는 T-101, T-102, I-08, M-03입니다.
5. `assets/report-template.md` 형식으로 초안을 작성합니다. 회의 메모 M-03이 있으면 다음 주 목요일 검토 예정으로 적습니다.
6. 기간·상태·숫자·근거를 입력과 대조하고, 누락 자료가 없는 것처럼 보이지 않게 확인합니다.
7. 초안을 사람에게 제시하고 검토를 요청합니다. 외부 전송은 이 절차에 포함되지 않습니다.

## 예외
- 자료 누락: 해당 항목을 `미확인`으로 표시하고, 무엇을 확인하지 못했는지 적습니다. M-03이 없더라도 I-08에서 확인된 막힘을 지우지 않습니다.
- 상충 자료: 두 근거를 모두 보존하고 `상충 — 확인 필요`로 남깁니다. 확인 없이 상태 하나를 고르지 않습니다.
- 비해당 요청: 주간업무 보고서 초안이 아니면 이 스킬을 선택하지 않습니다.

## 완료 기준
- 완료·진행·막힘 세 구역이 있습니다.
- 각 업무 주장에 원자료 식별자가 연결됩니다.
- 누락·상충 자료가 있으면 명시되어 있고, 추측한 사실이 없습니다.
- 결과는 초안이며 외부로 전송되지 않습니다.

## 시험
`assets/test-cases.json`의 정상·누락·상충·비해당 네 사례로 선택과 결과를 확인합니다. 이 예제는 호스트에 자동 설치되지 않습니다.
