# Agent Skill 한국어 강의

[발표 본편](https://pheanor-agent.github.io/agent-skill-lecture/)은 23장, 60분입니다. 에이전트를 처음 쓰는 분부터 어느 정도 써 본 분까지를 대상으로, '회의록 정리' 예시 하나로 처음부터 끝까지 이어 갑니다.

| 막 | 장 | 시간 |
| --- | --- | --- |
| 1막 · 왜 필요한가 | 1–5 | 0–10분 |
| 2막 · 어떻게 움직이나 | 6–11 | 10–24분 |
| 3막 · 무엇과 다른가 (Tool call · MCP · AGENTS.md · Skill) | 12–19 | 24–40분 |
| 4막 · 직접 만들기 (실습 10분, 질의응답 포함) | 20–23 | 40–60분 |

## 조작

- `→` / `←` 또는 화면 클릭(왼쪽 1/3은 이전): 장 이동
- 장 안의 강조는 자동으로 재생됩니다. 처음에는 단계가 1초 간격으로 쌓이고, 이후에는 진하게 보이는 곳이 2초씩 순서대로 옮겨 가며 반복합니다.
- `스페이스` 또는 `P`: 자동 재생 일시정지 · `R`: 이 장을 처음부터 다시 재생 · `F`: 전체 화면 · `Home` / `End`: 처음 / 끝
- 주소 끝에 `#7`처럼 장 번호를 붙이면 그 장부터 엽니다. `?all=1`은 모든 단계를 펼친 정지 화면입니다.
- 운영체제에서 동작 줄이기를 켜면 움직임 없이 정지 화면으로 보입니다.
