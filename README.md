# Agent Skill · 자동 시연 강의

[강의 열기](https://pheanor-agent.github.io/agent-skill-lecture/) · [강의 노트](https://pheanor-agent.github.io/agent-skill-lecture/notes.html)

한국어 36장, 본 강의55분+Q&A5분. 주간보고서 한 사례로 Agent Skill의 유래·사용법과 Tool call, AGENTS.md, MCP의 차이를 설명합니다.

## 발표

- 창을 열면 슬라이드가 화면에 맞게 표시되고, 데모 장면은 자동으로 시작됩니다. 완성 결과를 충분히 보여준 뒤 반복합니다. 슬라이드 자체는 자동으로 넘어가지 않습니다.
- ← / → / Space: 앞뒤 이동. 마우스를 움직이면 작은 이동 메뉴가 나타납니다.
- R: 현재 데모 처음부터. P: 데모 일시정지·이어서. F: 전체 화면.
- 하단 페이지 번호: 목차. ⋯: 목차, 재생 보조, 전체 화면, 별도 강의 노트·출처·인쇄.
- 장별 시간과 발표 노트는 청중 화면에 표시하지 않고 별도 노트 페이지에 둡니다.

## 자동 시연과 화면 배치

12개 조작형 장면을 자동 타임라인으로 바꿨습니다. 퀴즈의 가상 클릭이나 입력 커서 대신 설명·분류·비교 결과를 의미 단위로 보여줍니다. 실제 API 호출이나 개인정보 입력은 없습니다. 화면을 떠나면 타이머가 정리되고 숨겨진 탭·열린 메뉴에서는 정지합니다. 모션 감소 설정에서는 설명이 완결된 정지 도식을 표시합니다.

발표 캔버스는 모든 해상도에서1600×900 좌표를 유지하고 전체를 같은 비율로 확대·축소합니다. 선과 노드가 별도로 재배치되지 않습니다. 휴대폰 세로 화면에서도 같은 구도를 유지하므로 긴 글은 별도 노트에서 읽고, 발표는 가로 화면을 활용할 수 있습니다.

## 자료와 수정

- `astra-scenes.js/css`: 아스트라가 설계한36장 장면. 의미 색과 한 장 한 메시지, 밝고 어두운 강의 호흡을 유지합니다.
- `auto-demo.js`: 자동 시연 순서·대기·반복·정지 프레임 및 관련 발표 노트.
- `deck.js`, `ui.css`, `index.html`: 단순한 발표 인터페이스와 고정 좌표 캔버스.
- `notes.html`: 36장 설명과 전환 멘트. `sources.html`: 공식 원문·확인 날짜·디자인 참고.
- `examples/weekly-brief/`: SKILL.md·합성 자료·서식·정상/누락/상충/비해당 테스트 예제. 자동 설치되지 않습니다.

정적 파일만 사용하며 오프라인에서도 `index.html`을 열어 발표할 수 있습니다. 기존 p-hermes v1/v2, reveal.js Auto-Animate, Slidev Animation, impress.js의 디자인 원리를 참고했으며 구체 링크는 출처 페이지에 있습니다. 자체 코드·원고는 MIT, 로컬 Pretendard는 `assets/PRETENDARD-OFL.txt`를 따릅니다.
