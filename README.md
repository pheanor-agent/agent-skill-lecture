# 매번 설명하지 않아도, 제대로 일하게 만들기

Agent Skill 강의용 한국어 인터랙티브 HTML. 36장, 본 강의 55분과 질의응답 5분으로 구성했습니다. 고정된 합성 주간업무 자료를 사용하며 실제 API 호출은 없습니다.

## 시작

`index.html`을 브라우저에서 열면 됩니다. 오프라인 file:// 실행을 지원하며, 선택적으로 `python3 -m http.server 8000` 후 `http://localhost:8000`을 사용할 수 있습니다. 외부 라이브러리·CDN은 사용하지 않습니다.

## 조작

- ←/→, PageUp/PageDown: 이전/다음 장
- Home/End: 첫 장/마지막 장
- N: 발표 노트 표시/숨김
- 목차 버튼: 목차 열기, Esc: 닫기
- 브라우저 주소 `#s12` 등으로 장면 공유 및 뒤로/앞으로 이동
- 목차, 읽기 모드, 전체화면, 모션 켜기/끄기, 인쇄를 지원합니다.
- 텍스트 입력·선택 컨트롤에서는 내비게이션 단축키를 가로채지 않습니다.
- 21번 데모: 재생·일시정지·단계 이동·초기화. 장면을 벗어나면 기존 장면의 동작이 정리됩니다.

## 60분 시간표

36장 전체 시간은 3600초로 검증됩니다: 앞 35장 3300초(55분) + 36장 Q&A 300초(5분). 장별 배정·핵심 설명·전환 멘트는 `notes.html`에 모두 있습니다.

1–3 반복 업무의 문제 제기와 참여 (4분)
4–6 에이전트 루프와 Tool call (4분 15초)
7–11 MCP·공통 지침과 분류 활동 (7분 30초)
12–20 Skill 구조·선택·호스트별 사용 (13분 45초)
21 통합 데모 (2분)
22–27 누락·작성·검증·적용 판단 (9분 45초)
28–34 개념 조합·진단·작성 실습 (12분)
35 정리 (1분 45초)
36 Q&A (5분)

## 파일 구성

- `astra-scenes.js`, `astra-scenes.css`: 아스트라가 구현한 36개의 장면별 HTML/SVG와 상호작용, 장면 스타일.
- `deck.js`, `ui.css`, `index.html`: 비례 캔버스, 내비게이션, 목차, 노트, 모션 설정, 인쇄, 읽기 모드.
- `notes.html`, `notes.js`: 장별 노트·전환·시간표 및 정지 프레임.
- `sources.html`: 주장과 공식 원문, 디자인 원리 참고 및 확인일.
- `examples/weekly-brief/`: 합성 T-101/T-102/I-08/M-03 자료, Skill, 템플릿, 정상·누락·상충·비해당 테스트.
- `assets/`: 오프라인 Pretendard subset과 OFL.

## 내용과 디자인

전체 서사의 정본은 2026-11-04 확정된 아스트라 설계와 `astra-scenes.js` 장면입니다. ‘작업대와 설명서’ 아트디렉션에서 보고서 결과를 중심으로 Tool call(행동), MCP(연결), AGENTS.md(공통 기준), Skill(업무 절차)을 상보적으로 설명합니다. 1600×900 논리 캔버스, 따뜻한 종이색과 어두운 구획, 역할별 색, 도형의 연속성과 의미 있는 모션을 사용합니다. p-hermes v1/v2와 reveal.js, Slidev, impress.js는 디자인 원리만 참고했고 코드·스타일을 복사하지 않았습니다. 근거와 링크는 `sources.html`을 참조하세요.

## 수정과 라이선스

장면의 문구·노트·시간·전환·상호작용은 `astra-scenes.js`, 색상·장면 구성은 `astra-scenes.css`, 내비게이션과 표시 방식은 `deck.js`/`ui.css`에서 수정합니다. `node --check deck.js` 및 `node --check astra-scenes.js`로 구문을 검사할 수 있습니다. 예제 Skill은 복사해 쓸 수 있는 교육자료이며 이 저장소에서 자동 활성화되지 않습니다. 저장소의 자체 코드·원고는 MIT (`LICENSE`); Pretendard는 동봉된 `assets/PRETENDARD-OFL.txt` 조건을 따릅니다.
